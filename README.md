# Etch-a-Sketch 🎨

마우스를 움직이면 픽셀처럼 색이 칠해지는 스케치 패드 웹 애플리케이션입니다.
순수 **HTML, CSS, JavaScript**로 구현했으며, [The Odin Project](https://www.theodinproject.com/)의 Foundations 과정 프로젝트입니다.

## 📌 프로젝트 소개

화면에 16x16 정사각형 그리드를 만들고, 마우스가 칸 위를 지나가면 색이 칠해져
펜으로 그림을 그리듯 흔적이 남는 인터랙티브한 그림판입니다.
버튼을 눌러 그리드의 해상도(한 변당 칸 수)를 자유롭게 바꿀 수도 있습니다.

## ✨ 주요 기능

- **JavaScript로 동적 그리드 생성** — HTML에 직접 div를 복사·붙여넣지 않고, JS로 그리드를 만듭니다.
- **Flexbox 레이아웃** — CSS Grid 대신 Flexbox를 사용해 칸들을 격자 형태로 배치합니다.
- **호버(Hover) 그리기 효과** — 마우스가 칸에 들어오면 색이 바뀌어 흔적을 남깁니다.
- **그리드 크기 변경** — 상단 버튼을 누르면 한 변당 칸 수를 입력받아(최대 100), 동일한 전체 크기(예: 960px) 안에서 새 그리드를 다시 그립니다.

### 🌟 추가 도전 (Extra Credit)

- **랜덤 색상** — 칸과 상호작용할 때마다 RGB 값을 무작위로 지정합니다.
- **점진적 어두워짐** — 상호작용할 때마다 칸이 10%씩 어두워져, 10번 만에 완전히 칠해집니다. (CSS `opacity` 속성 활용)

## 🛠 사용 기술

| 기술           | 활용 내용                                                           |
| -------------- | ------------------------------------------------------------------- |
| **HTML**       | 컨테이너 div, 버튼 등 기본 구조 작성                                |
| **CSS**        | Flexbox 레이아웃, 칸 스타일링, 호버/투명도 효과                     |
| **JavaScript** | DOM 조작, 동적 그리드 생성, 이벤트 리스너, 사용자 입력(prompt) 처리 |

## 🚀 실행 방법

1. 저장소를 클론합니다.
   ```bash
   git clone git@github.com:Jhoncarmack/Etch-a-sketch_2026.git
   ```
2. `index.html` 파일을 브라우저에서 엽니다.
3. 마우스를 그리드 위로 움직여 그림을 그려보세요!
4. 상단 버튼을 눌러 그리드 크기를 바꿔보세요.

## 📂 파일 구조

```
etch-a-sketch/
├── index.html      # 페이지 구조 및 컨테이너 div
├── style.css       # 그리드 및 칸 스타일
└── script.js       # 그리드 생성 및 인터랙션 로직
```

## 🎯 이 프로젝트로 입증하는 역량

이 프로젝트를 완료하면 다음 기술을 다룰 수 있음을 보여줍니다.

- JavaScript를 이용한 **DOM 요소 동적 생성 및 조작**
- `mouseover`, `click` 등 **이벤트 리스너** 설정과 활용
- **Flexbox**를 이용한 반응형 격자 레이아웃 구성
- 사용자 입력(`prompt`)을 받아 **UI를 동적으로 다시 렌더링**하는 흐름 설계
- 클래스 토글 / 인라인 스타일 변경 등 **여러 방식의 스타일 제어**
- (추가 도전 시) RGB·opacity를 다루는 **색상 연산 로직** 구현
- **Git을 이용한 버전 관리** (early & often 커밋 습관)
